# ShipBoost - Smart Free Shipping Bar & Cart Progress Upsell for Shopify

A high-conversion Shopify App designed to increase Average Order Value (AOV) for e-commerce merchants.

## Features
- **Dynamic Calculation**: Tracks `/cart.js` in real time to calculate the remaining amount to reach free shipping.
- **Animated Progress Bar**: Visual feedback motivating shoppers to add more items.
- **Live Preview Dashboard**: Styled with Shopify Polaris design guidelines.
- **Theme App Extension (Online Store 2.0)**: Clean Liquid block and embed with zero theme file modification.
- **Shopify Billing Integration**: Ready-to-monetize Pro tier ($9.99/mo).
- **Zero-Dependency Native Architecture**: Runs out of the box with standard Node.js.

## Getting Started

1. Clone or extract the repository.
2. Run `node server.js` or `npm start`.
3. Open `http://localhost:3000` to preview the admin dashboard.
4. Deploy to Render, Railway, or Vercel with 1-click.
